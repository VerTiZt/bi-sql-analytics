CTE (Common Table Expressions) — это временные именованные наборы данных, которые существуют только
во время выполнения твоего запроса.
Они объявляются с помощью ключевого слова WITH в самом начале скрипта.
главное: поскольку мы не можем напрямую отфильтровать результат оконной функции в блоке WHERE
(база данных выдаст ошибку), мы объединяем мощь CTE и оконных функций.
Мы рассчитываем ранги внутри временной таблицы, а фильтруем их уже во внешнем запросе.


Базовый синтаксис:

WITH my_temp_table AS (
    -- Внутренний запрос: собираем данные и раздаем места
    SELECT ...
)
-- Внешний запрос: обращаемся к CTE как к обычной таблице
SELECT ...
FROM my_temp_table
WHERE ... = 1;
