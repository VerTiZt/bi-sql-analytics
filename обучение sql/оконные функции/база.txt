Главное отличие от обычного GROUP BY: оконные функции не схлопывают строки. Если на 
входе 100 строк — на выходе останется 100 строк, просто рядом появится вычисленное значение по группе.

Анатомия любого окна строится из трех кирпичей в конструкции OVER (...):
SQL
ФУНКЦИЯ() OVER (
    PARTITION BY колонка_группировки -- 1. «Комнаты»: на какие группы делим данные
    ORDER BY колонка_сортировки      -- 2. «Порядок»: в каком порядке обходим строки в комнате
    ROWS BETWEEN ... AND ...         -- 3. «Фрейм»: сколько строк до/после текущей захватываем
)

3 основные группы функций, которые нужно знать:
Ранжирующие (нумерация и топы):

ROW_NUMBER() — строгая нумерация строк подряд (1, 2, 3, 4), дубликатов ранга не бывает.

RANK() — если значения одинаковые, дает одинаковый ранг, но пропускает следующие номера (1, 2, 2, 4).

DENSE_RANK() — дает одинаковый ранг при совпадении, но не пропускает номера (1, 2, 2, 3).

Смещения (динамика и сравнение):

LAG(col, 1) — достает значение из предыдущей строки (незаменимо для расчета дельты к прошлому месяцу или дней между заказами).

LEAD(col, 1) — достает значение из следующей строки.

Агрегатные с окном (накопительные итоги и доли):

SUM(amount) OVER (PARTITION BY client_id ORDER BY date ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) — классический нарастающий итог.

amount / SUM(amount) OVER (PARTITION BY category) — расчет доли строки от общей суммы категории без подзапросов.


!БЕЗ ORDER BY: avg(...) over (partition by first_name) считает глобальное среднее по всем заказам клиента и приписывает это готовое число 
каждой его строке. Это именно то, что нам нужно.

!С ORDER BY: avg(...) over (partition by first_name order by order_date) включает режим скользящего (нарастающего) итога. 
База считает среднее только для первой строки, затем для первой+второй, затем для 1+2+3. Общая средняя цифра появится 
только в самой последней строке, а остальные исказятся.
!!!Правило: ORDER BY внутри OVER обязателен для рейтингов (ROW_NUMBER), смещений (LAG) и накопительной кассы. 
!!!Для подсчета общей суммы или среднего по клиенту его ставить нельзя
