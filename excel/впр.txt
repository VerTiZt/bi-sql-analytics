ТЕОРИЯ: ВПР (VLOOKUP) — базовый JOIN в Excel
Функция ВПР (Вертикальный Просмотр) ищет нужное тебе значение в левой колонке другой таблицы и 
возвращает данные из соседних ячеек.
Ее синтаксис состоит из 4 аргументов:
=ВПР(что_ищем; где_ищем; номер_столбца_для_возврата; 0)

Что ищем: Ячейка с ID или названием, которое нужно найти (например, ID товара). в исходной таблице

Где ищем: Диапазон справочника, где будем искать. Важное ограничение: столбец, 
по которому мы ищем, обязан быть самым крайним слева в выделенном диапазоне.

Номер столбца: Порядковый номер колонки в выделенном диапазоне, 
из которой нужно забрать данные (считая слева направо: 1, 2, 3...). то есть откуда берем данные
(во второй таблице)

0 (Ложь): Это критически важный аргумент. Он заставляет функцию искать точное совпадение. 
Если забудешь поставить 0, Excel найдет «примерно похожее» значение и разрушит весь твой отчет.
