git add . (выбрать новые/измененные файлы)

git commit -m "описание работы" (сохранить их в локальную историю)

git push (отправить в облако — флаг -u, origin и main больше писать не нужно, 
так как Git уже запомнил маршрут).

---
перемещаю файл base.sql в папку old (mv - move)
git mv base.sql old/
---
Удаление файла:
git rm --cached "путь/к/файлу.ext"

Удаление папки (флаг -r нужен для рекурсивного удаления содержимого):
git rm -r --cached "путь/к/папке"
Чтобы этот файл или папка не добавились обратно при следующем git add ., 
внеси путь к ним в файл .gitignore

!удаляем папку old из отслеживания git (и с гитхаба) - пример!
git rm -r --cached old
---
добавляем два конкретных файла (в папке!) !!!
git add "оконные функции/lag_lead.sql" "оконные функции/row_number_rank.sql"
---
git add . индексирует изменения только в текущей папке и всех её подпапках (относительно того места, где ты сейчас находишься в терминале).
git add -A индексирует изменения во всём проекте, даже если в терминале ты находишься глубоко в какой-то подпапке.
---
допустим, я сделал git add .
но часть файлов я хотел бы убрать

# убрать конкретный файл из индекса
git restore --staged path/to/file.txt

# убрать целую папку со всем содержимым
git restore --staged path/to/folder/

# убрать вообще все добавленные файлы (полная отмена git add .)
git restore --staged .
